# Findings D — Store, ASO & other livestreams (for Nagly)

Key sources: 0915_app_approval (2026), 0922_aso_ai_agents (2026), 0911_aso_zero_to_1k (2025), 0821_publishing_stores (2025), 0806_replit (2026), 0825_kotlin_multiplatform (2026). Others were sponsor/technical; none mention the Peace Prize.

## 1. Points relevant to winning
- Grand Prize = strongest traction/growth/user count in the window (0806). Lead with rate of change: 41 new customers in 28 days, Journey CTRs, 3 releases in 5 days.
- An entry that wins multiple categories only gets the highest prize (0806) — entering several categories is free.
- Judges want creativity, real market, polished UI/animations; the video should show why someone would download and pay, with the delight moments (0825). Judges don't read code.
- App must be public in the US by the deadline; Android in review can't be claimed as live (0915).
- Apple scrutinises health/medical claims; avoid "improves adherence / stay healthy / doctor-recommended" in the listing and video (0915).
- Listing and screenshots must match real UI; no "coming soon"; iOS listing must not mention ads/Android; include the Terms of Use URL (0915, 0821).
- Small focused updates review faster; expedite requests can cite a marketing event but shouldn't name RevenueCat/Shipaton (0915).
- Winners also get a Times Square demo day (0922).

## 2. Quick App Store / ASO wins (metadata only, optional)
1. Title = top 1–2 keywords, subtitle = next tier, never repeat words across title/subtitle/keywords (0911, 0922).
2. Target long-tail problem phrases ("water reminder for adults", "pill reminder for parents") (0922).
3. First screenshot: benefit headline readable in 1 s; real UI only (0911, 0915).
4. Description with concrete use cases for AI-search referrals (0922).
5. Promotional text can change without review (0821).
6. Nominate the app for featuring; consider an In-App Event (0911, 0922).
7. In-app review prompt after a "proud" moment; reply to reviews (0911).

## 3. Additions to prize answers
- Grand Prize: "what we did since launch" — 3 releases in 5 days, targeting/offering experiments, Journeys with measured CTRs; show growth as a rate.
- Design: name 2–3 delight moments (mood avatar, tilt physics, pleading paywall) and show each in the first 2 minutes; lock-screen actions as a design choice.
- Peace Prize: keep claims defensible — on-device, no account, free Mom tier forever; no medical-outcome claims.
